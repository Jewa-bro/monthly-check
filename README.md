# 배송 실적

일별 배송 건수를 기록하고, **정산월(매월 26일 ~ 다음달 25일)** 누적 실적과 금액을 확인하는 앱입니다.
설치 없이 브라우저에서 열면 바로 쓸 수 있고, 폰에서는 앱처럼 설치할 수 있습니다.

## 폰에 설치하기

1. 폰 브라우저로 배포된 주소를 엽니다.
2. **안드로이드(Chrome)**: 우측 상단 `⋮` → **앱 설치** (또는 홈 화면에 추가)
   **아이폰(Safari)**: 하단 공유 버튼 → **홈 화면에 추가**
3. 홈 화면에 생긴 아이콘으로 열면 브라우저 주소창 없이 앱처럼 실행됩니다. 인터넷이 없어도 열립니다.

## 사용법

- 홈 화면 아래 **오늘 배송 입력하기** → 숫자 입력 → **저장하기**
- 날짜를 바꾸려면 입력 화면의 **날짜** 줄을 눌러 목록에서 고릅니다. (이미 기록한 날은 건수가 함께 보입니다)
- 홈 상단 `‹ ›` 로 지난 정산월을 넘겨봅니다.
- **단가**를 한 번 넣으면 그 달 총액이 자동 계산됩니다. 단가는 달마다 따로 저장됩니다.
- 기록을 고치거나 지우려면 홈의 날짜 목록에서 그 날을 누릅니다.

## 데이터

- 실적은 서버로 전송되지 않고 **기기 안(localStorage)에만** 저장됩니다.
- 따라서 PC와 폰의 기록은 서로 공유되지 않습니다.
- 브라우저 저장소를 지우면 기록이 사라지므로, `지난 달 실적 · 백업` → **백업 파일 저장**으로 주기적으로 내려받아 두세요. 다른 기기로 옮길 때는 **백업 불러오기**를 쓰면 됩니다.
